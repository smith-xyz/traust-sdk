# traust-core REST API clients

Generated Go clients for traust-core's REST adapter (`traust-server`), plus
hand-written bindings in `client.go` (bearer-token auth from a rotating file,
bounded retries on transient GET failures, typed problem+json errors, cursor
pagination).

## Input

`openapi.json` is traust-core's `make api-check` output, checked in so
generation is reproducible:

- **Preview input:** 48 paths, generated by `make api-check` from the
  owner-backed Core native worker handoff at
  `fae0e58741dc6749ee49ff547f3182ba06f59a43`, based on Core `development`
  `5e0cfc5d7195ebb65ae1e76ef4083288414c37c7`.
- The original recording prerequisites (#266, #259, #261 and #260) are merged.
  The additional explicit-start capability, authored unjudged intake,
  authoritative source/triage binding reads and artifact reads remain a held
  development review candidate. This snapshot does not assert deployment.
- Keep this SDK/worker cutover held until the coordinated Core changes and
  producer/caller changes are reviewed. Regenerate against the merged Core API
  before landing if its contract changes in review.
- To update the input, run Core's `make api-check`, copy its
  `.openapi/openapi.json` here, record the exact source ref above, then run
  `make api-generate` from `go/`. The checked-in snapshot makes SDK generation
  reproducible without a sibling Core checkout.

`normalize.py` rewrites the two 3.1-isms kin-openapi cannot read (numeric
`exclusiveMinimum`/`exclusiveMaximum`; pydantic's `anyOf: [schema,
{type: "null"}]` Optional) into their 3.0 forms, producing
`openapi-3.0.json`. It also supplies `x-enum-varnames` for the new `SourceType`
enum, keeping its Go constants namespaced so the generator does not rename
the existing `SourceChannel` constants (`Commit`, `Interactive`, `Jira`,
`MrComment`). Wire values and validation constraints are unchanged. When Core's
OpenAPI publishing lands with each release, this directory tracks the released
artifact instead.

## Generating

```sh
make -C .. api-generate   # from go/, or: make api-generate from go/
```

runs `normalize.py` then `go tool oapi-codegen` (pinned in go.mod's tool
directives) over `oapi-codegen.yaml`. `client.gen.go` is generated; never
edit it — extend `client.go` instead. CI's drift check regenerates and fails
on a diff.
